# yt-dlp Local Web Downloader

ブラウザ上のきれいなUIから動画のダウンロード進捗（％）をリアルタイムに確認し、PCの「ダウンロード」フォルダに直接保存できる自分専用のWebツールです。

## 🛠️ 前提条件 (Requirements)

このアプリを動かすには、お使いのパソコンに以下の3つのツールがあらかじめインストールされている必要があります。

1. **Node.js** (v18 以上推奨)
   - バックエンドサーバー（`server.js`）を実行するために必要です。
2. **yt-dlp**
   - 動画データを解析・ダウンロードするコアプログラムです。常に最新版にアップデートしておいてください。
3. **ffmpeg**
   - `yt-dlp` が最高画質の映像と音声を1つの動画ファイル（.mp4など）に結合するために必須です。

---

## 🚀 使い方 (Usage)

### 1. 依存ライブラリのインストール
プロジェクトのフォルダをターミナル（またはコマンドプロンプト）で開き、以下のコマンドを実行して必要なNode.jsパッケージをインストールします。

```bash
npm install
```

### 2. サーバーの起動
以下のコマンドでローカルサーバーを立ち上げます。

```bash
node server.js
```
ターミナルに `【自分専用ツール】 http://localhost:3000 をブラウザで開いてください` と表示されれば成功です。

### 3. ブラウザで実行
1. ブラウザを開き、`http://localhost:3000` にアクセスします。
2. ダウンロードしたい動画のURLをペーストし、「ダウンロード開始」をクリックします。
3. プログレスバーが100%になると、お使いのPCの **「ダウンロード」フォルダ** 内に動画ファイルが直接保存されます。
